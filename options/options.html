Overlay Ink

A transparent note you can write on top of any page.

How it works

  1. Click the Overlay Ink icon in the toolbar (or press Alt+Shift+O) on any page.
  2. The overlay opens in Edit mode, with a small toolbar at the top: pick a colour, size, font and background, then start typing.
  3. Switch to View mode to keep the note on screen while you use the page normally. Esc inside the note does the same thing.
  4. Click the toolbar icon again, or press Alt+Shift+H, to hide it. Your text is kept and reappears next time.

In Edit mode the page underneath stops responding to clicks so nothing moves while you write — that is deliberate. In View mode every click goes to the page as usual, except on the small toolbar itself.

Keyboard shortcuts

  • Alt+Shift+OShow or hide the overlay (same as clicking the icon)
  • Alt+Shift+HHide the overlay while it is open
  • EscWhile typing: leave Edit mode and go to View

Open brave://extensions/shortcuts and look for “Overlay Ink”.

Your data

The note text and these settings are stored locally in your browser profile. Nothing is uploaded anywhere.

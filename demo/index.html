This page is pretending to be a website

Click the purple icon in the bar above — that is exactly what the Overlay Ink toolbar button does in Brave. The transparent layer appears on top of this page, with a small toolbar of its own.

Try this

  1. Type straight away — the overlay opens in Edit mode and the caret is already in place.
  2. Pick an ink colour, size, font or background from the top toolbar.
  3. Hit Esc or click View — now the note stays put and this page becomes clickable again.
  4. Click the icon again (or press Alt+Shift+H) to hide it. Your text is remembered.

What it is

  • A fully transparent layer — only your text is drawn, nothing else.
  • The note follows you to every site and every tab, so you can jot something down while reading.
  • Everything stays on your machine: the text lives in the extension's local storage.

Why the page stops responding in Edit mode

While you write, clicks have to reach the note instead of the links underneath, otherwise the page would navigate away mid-sentence. That is what Edit mode does. Switch to View and every click goes back to the page, so you can keep reading, scrolling and clicking with the note floating on top of everything.

The toolbar at the top of the overlay stays clickable in both modes, and it fades out of the way in View mode until you hover over it.

Built for reading

Long passages of text are here on purpose: colour, size and the text outline option exist because a note needs to stay readable over a white article, a dark terminal or a photo. Set the background slider above 0% if you want a faint panel behind the words.

This demo runs the extension's real content script with a small stand-in for the browser APIs, so what you see in the overlay is the shipped behaviour. In a real installation the toolbar icon in Brave toggles it on any page (browser pages like brave://settings are off limits, as always for extensions).

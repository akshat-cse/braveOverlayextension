Only the text is drawn on the page — the overlay itself stays fully transparent. Background above 0% adds a faint panel behind the note.

Toggle from the toolbar icon or Alt+Shift+O.

Open brave://extensions/shortcuts and find “Overlay Ink”.

Edit mode pauses the page so you can write; View mode leaves the note visible and keeps the page clickable. Esc in the note switches to View.
